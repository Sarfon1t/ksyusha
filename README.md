# Particle Teddy 💜

A browser particle animation: an outlined gift transforms into a teddy bear made from thousands of glowing particles.

## Run
Open `index.html` in a modern browser. No Python or libraries are needed.

## GitHub Pages
Upload `index.html`, `style.css`, `script.js`, and `README.md` to the root of a public repository. Then open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, and save.

## Features
- 2,600–6,200 glowing particles depending on screen size.
- Clear gift outline, then teddy outline.
- Extra twinkling sparkles.
- Replay and floating-heart buttons.
