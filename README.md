# Particle Teddy 💜

A browser-based particle animation: a glowing gift gradually transforms into a teddy bear with an **I LOVE YOU** heart.

## Run it

You do not need Python or any libraries.

- Open `index.html` in a browser, or
- Upload all three files to a GitHub repository and enable GitHub Pages.

## Publish with GitHub Pages

1. Create a new **Public** repository on GitHub, for example `particle-teddy`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait a minute and refresh the Pages section. GitHub will show your website link.

## Controls

- **Replay** restarts the gift-to-teddy transformation.
- **Send love** creates floating hearts.

The animation uses HTML Canvas and JavaScript, so it works in modern desktop and mobile browsers.
